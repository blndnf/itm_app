====================================================
  MSAT Reviewer - ICPMH Audit Trail Analyzer
====================================================

Dieses Repository enthält PowerShell-Tools zur automatisierten Analyse
von Audit Trail PDFs aus MSAT (Multi-System Audit Trail).


====================================================
ENTHALTENE SKRIPTE
====================================================

1. MSAT_RM_0.ps1 (Hauptskript - Automatisierte Analyse)
   └─ Start via: MSAT_RM.bat

2. Debug.ps1 (Debugging-Tool - Manuelle Analyse)
   └─ Start via: Debug.bat


====================================================
1. MSAT_RM_0.ps1 - HAUPTSKRIPT
====================================================

ZWECK:
------
Automatisierte Batch-Analyse von Audit Trail PDFs.
Filtert und extrahiert relevante Einträge basierend auf:
  - Zielgruppen: ICPMHAdmin, ICPMHOperators, ICPMHManagers, ASnT
  - Reason: Muss vorhanden sein (nicht "Autogenerated")

Erstellt einen detaillierten Report mit allen Findings.


START:
------
1. Doppelklick auf MSAT_RM.bat
2. Wähle Sortiermodus:
   - S = Nach Seitenzahl sortiert (empfohlen für Seite-für-Seite-Analyse)
   - U = Nach User sortiert
3. Bestätige Analyse des AT_IN Ordners: J


EINGABE:
--------
PDFs im Verzeichnis: AT_IN/
  - Alle PDFs in diesem Ordner werden automatisch analysiert
  - Unterstützt mehrseitige PDFs
  - Unterstützt mehrseitige Einträge (über Seitengrenzen hinweg)


AUSGABE:
--------
Report im Verzeichnis: AT_OUT/
  - Dateiname: ICPMH_RE<timestamp>.txt
  - Format: Detaillierte Auflistung aller Findings
  - Gruppiert nach PDF-Datei
  - Zeigt: User, Group, Time, Reason, Error Message, Action
  - Gesamtanzahl Findings


BEISPIEL-OUTPUT:
----------------

----------------------------------------------------

  Action: 'Create'

Seite 3 | User: Maria Schmidt | Group: ICPMHManagers | 2024-09-16 14:30:12 GMT+02:00
  Reason: 'Manual intervention required' | Error Message: 'Connection timeout'
  ...


====================================================
2. DEBUG.PS1 - DEBUGGING-TOOL
====================================================

ZWECK:
------
Manuelle Einzeldatei-Analyse zur Fehlersuche und Validierung.
Zeigt detaillierte Debug-Informationen:
  - Y-Gruppierung (physische Zeilen)
  - Header-Erkennung
  - Spalten-Definition
  - Tabellenzeilen-Erkennung
  - Erste Zeile Detail-Extraktion
  - Vollständige rekonstruierte Tabelle
  - Footer-Bereinigung (letzte Zeile)


START:
------
1. Doppelklick auf Debug.bat
2. Wähle PDF-Datei im Datei-Dialog


AUSGABE:
--------
Debug-Report im Verzeichnis: (gleiches Verzeichnis wie Skript)
  - Dateiname: <pdfname>_debug_super_detail.txt
  - Format: Sehr detailliert mit allen Verarbeitungsschritten
  - Enthält: Chunk-Koordinaten, Y-Gruppen, Spalten-Bereiche
  - Zeigt: Rekonstruierte Tabelle (wie Debug.ps1 sie interpretiert)


ANWENDUNGSFÄLLE:
----------------
- PDF wird nicht korrekt geparst → Debug.ps1 zeigt, warum
- Header nicht gefunden → Debug zeigt alle Y-Gruppen
- Spalten falsch erkannt → Debug zeigt XStart/XEnd Bereiche
- Footer-Fragmente in Zellen → Debug zeigt Bereinigung
- Mehrseitige Einträge → Debug zeigt Seiten-für-Seite Details

====================================================
TECHNISCHE DETAILS
====================================================

PDF-VERARBEITUNG:
-----------------
- Koordinaten-basierte Text-Extraktion mit iTextSharp
- Y-Gruppierung identifiziert physische Zeilen (Toleranz: 0.5 Pixel)
- X-Positionen definieren Spalten-Bereiche (XStart bis XEnd)
- Spalten werden von Seite 1 extrahiert und für alle Seiten verwendet


MULTI-PAGE-SUPPORT:
-------------------
- Header wird nur auf Seite 1 gesucht
- Folgeseiten: Nur Tabelleninhalt (kein Header)
- User-Eintrag markiert neue Tabellenzeile
- Mehrseitige Einträge werden automatisch zusammengeführt:
  * Start-Seite: Von User-Y bis Seitenende
  * Zwischenseiten: Gesamter Inhalt (außer Header/Footer-Bereich)
  * End-Seite: Von Seitenanfang bis nächster User-Y


TEXT-NORMALISIERUNG:
--------------------
- Chunks werden OHNE Leerzeichen zusammengefügt: -join ""
- Mehrfache Leerzeichen werden normalisiert: -replace "\s+" " "
- Verhindert "I n g o  W e d e m e y e r"
- Resultat: "Ingo Wedemeyer"


FOOTER-BEREINIGUNG:
-------------------
Nur letzte Tabellenzeile wird bereinigt:
  - User: Entfernt "ion Date: YYYY-MM-DD" Pattern
  - Group: Schneidet nach Gruppennamen ab (ICPMHAdmin|ICPMHOperators|ICPMHManagers|ASnT)
  - Time: Behält nur bis erstem GMT±HH:MM
  - Error Message: Entfernt "Page X/Y" Pattern


FILTER-KRITERIEN:
-----------------
MSAT_RM_0.ps1 filtert nach:
  1. Group LIKE "ICPMHAdmin" OR "ICPMHOperators" OR "ICPMHManagers" OR "ASnT"
  2. Reason ist NICHT leer UND NICHT "Autogenerated"


====================================================
TROUBLESHOOTING
====================================================

PROBLEM: "Keine Tabellenzeilen gefunden"
LÖSUNG:
  - Debug.ps1 verwenden, um zu sehen, wo User-Einträge erkannt werden
  - Prüfen: Wird Header gefunden?
  - Prüfen: Sind Spalten korrekt definiert?


PROBLEM: "Header nicht gefunden"
LÖSUNG:
  - PDF hat möglicherweise abweichende Struktur
  - Debug.ps1 zeigt alle Y-Gruppen → Wo ist der Header?
  - Evtl. Header-Pattern anpassen in Zeile ~204


PROBLEM: "Group-Spalte enthält Zeitfragmente"
LÖSUNG:
  - Bereits gelöst! Footer-Bereinigung schneidet nach Gruppennamen ab
  - Debug.ps1 zeigt "Group DEBUG" Output
  - Falls neue Gruppe: In Zeile ~213 hinzufügen


PROBLEM: "Mehrseitige Einträge fehlen"
LÖSUNG:
  - Multi-Page-Support ist implementiert
  - Debug.ps1 zeigt, ob User-Einträge auf allen Seiten erkannt werden
  - Prüfen: Y > 50 und Y < 500 (Header/Footer-Bereich)


PROBLEM: "Leerzeichen zwischen jedem Buchstaben"
LÖSUNG:
  - Bereits gelöst! Text-Normalisierung mit -join "" und -replace "\s+" " "
  - Falls noch vorhanden: Debug.ps1 prüfen


====================================================
ENTWICKLUNG & ANPASSUNGEN
====================================================

NEUE GRUPPE HINZUFÜGEN:
-----------------------
1. Öffne MSAT_RM_0.ps1
2. Zeile 51: Füge Gruppe zu $TargetGroups hinzu
   $TargetGroups = @("ICPMHAdmin", "ICPMHOperators", "ICPMHManagers", "ASnT", "NeueGruppe")
3. Zeile 166: Füge Gruppe zum Footer-Bereinigung-Pattern hinzu
   if ($cleaned -match "(ICPMHAdmin|ICPMHOperators|ICPMHManagers|ASnT|NeueGruppe)")


FILTER-KRITERIEN ÄNDERN:
-------------------------
1. Öffne MSAT_RM_0.ps1
2. Zeile 357-369: Passe Filter-Logik an
   - $groupMatch: Welche Gruppen?
   - $reasonValid: Welche Reasons?


Y-BEREICH FÜR FOLGESEITEN ANPASSEN:
------------------------------------
Wenn Header/Footer bei eurem PDF andere Y-Positionen haben:
1. Öffne MSAT_RM_0.ps1
2. Zeile 263: $y -lt 50  (Footer-Untergrenze)
3. Zeile 315/325: $_.Y -gt 50 -and $_.Y -lt 500  (Content-Bereich)
